# Little Whale

**A local-first agentic coding assistant designed for small language models.**

Little Whale is an independent fork of [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). It retains the upstream agent runtime, Cordis plugin architecture, web conversation experience, tools, sessions, plans, and subagents, while giving the product a different centre of gravity: models that run on your own hardware.

DeepSeek Harness can connect to local providers, but its defaults and onboarding are primarily designed around frontier-class hosted models. Little Whale makes local inference the normal path, with an editable OpenAI-compatible endpoint, model discovery, local privacy defaults, and development priorities shaped by smaller models.

Little Whale aims to remain compatible with DeepSeek Harness plugins and extensions wherever it retains the corresponding upstream contract.
