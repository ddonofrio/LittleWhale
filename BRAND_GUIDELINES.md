# Little Whale brand guidelines

Little Whale has its own product identity while clearly acknowledging the DeepSeek Harness project from which it is derived.

## Name

- Write the product name as **Little Whale**.
- Do not use **DeepSeek Harness**, **dsh**, or an upstream package name as the public product name.
- Use inherited identifiers such as `dsh`, `DSH_*`, and `@deepseek-ai/*` only when documenting an actual command, environment variable, package, or compatibility contract.

## Official assets

| Asset | Path | Use |
|---|---|---|
| Whale mark | `apps/web/public/little-whale-logo.png` | Square product icon and compact surfaces |
| Wordmark | `apps/web/public/little-whale-logo-text.png` | README, website headers, and wide layouts |
| Text mark | `apps/web/public/little-whale-text.png` | Layouts that already contain the whale mark |
| Favicon | `apps/web/public/favicon.png` | Browser and application icon |

Use the supplied assets without stretching, recolouring, outlining, or combining them with the DeepSeek logo.

## Product copy

- Describe Little Whale as an agentic coding assistant for small local models.
- Present local inference as the normal product path.
- Keep technical claims specific and verifiable.
- Keep upstream acknowledgement factual and separate from product promotion.

## Relationship with DeepSeek

Little Whale is an independent fork of DeepSeek Harness. It is not an official DeepSeek product and is not affiliated with or endorsed by DeepSeek.

Do not use DeepSeek trademarks, logos, or visual elements in a way that suggests sponsorship, partnership, certification, or official compatibility. Attribution belongs in documentation and legal notices; it must not be presented as Little Whale branding.
